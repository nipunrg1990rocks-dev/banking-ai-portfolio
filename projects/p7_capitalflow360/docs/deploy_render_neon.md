# Public demo on Render (free) with a Neon (free) database

> Not used: on 2026-11-16 Render's dashboard asked for a card for this service. The demo uses
> [Back4app Containers](deploy_back4app_neon.md) instead. This file and `render.yaml` are kept for anyone with a Render account.

The blueprint is `render.yaml` at the repository root. It deploys this folder's Dockerfile as one free web service.
The database is a Neon Free Postgres. Nothing in this setup needs a payment method. Do not add one: without it, going
over a free limit suspends the service until next month instead of billing.

Free-tier facts, checked 2026-11-16 against render.com/docs/free and neon.com/pricing:

| | Render free web service | Neon Free |
|---|---|---|
| Size | 0.1 CPU, 512 MB | up to 2 CU, scales to zero after 5 minutes idle |
| Limits | 750 instance hours a month per workspace; sleeps after 15 minutes idle, about a minute to wake | 1 GB storage, 100 CU-hours a month per project |
| Over the limit | suspended (bandwidth, build minutes are billed only if a payment method exists) | suspended or writes refused, never billed |

The app uses about 25 MB of storage and about 85 MB of memory. A test run with the same limits (0.1 CPU, 512 MB) took about
5.5 minutes on the first start, most of it loading the baseline, and served a dashboard in about 5 seconds.

## Steps

1. **Neon.** Sign in at https://console.neon.tech with GitHub. Create a project named `capitalflow360` in AWS US West (Oregon).
   Open **Connect** and copy the connection string. It starts with `postgresql://`.
2. **Render.** Sign in at https://dashboard.render.com with GitHub. Choose **New > Blueprint**, pick `banking-ai-portfolio`
   and branch `main`. Render reads `render.yaml` and asks for two values:
   - `CF360_DATABASE_URL`: paste the Neon connection string.
   - `CF360_DEMO_PASSWORD`: choose the password demo visitors will use.

   Choose **Apply**. `CF360_JWT_SECRET` is generated by Render.
3. The first deploy takes about 10 minutes: the image build, then the baseline load. The site is at
   `https://capitalflow360.onrender.com` (or the name Render shows).

If a first start is cut off during the load, the next start detects the half-finished load and loads it again (`cf360.bootstrap`).
